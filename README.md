
# Fraud Detection in Banking Transactions

## 📌 Project Overview
This project detects suspicious banking transactions using network analysis techniques.

## 🎯 Objective
To identify fraud patterns by analyzing relationships between bank accounts.

## 🛠️ Technologies Used
- Python
- Pandas
- NetworkX
- Matplotlib

## 📊 Features
- Graph-based transaction analysis
- Centrality-based fraud detection
- Network visualization

## 🚀 How to Run
1. Install libraries:
   pip install pandas networkx matplotlib

2. Run the code:
   python fraud.py

## 📷 Output
- Suspicious accounts detected
- Network graph visualization

## 📌 Conclusion
This project uses graph theory concepts to detect hidden fraud patterns effectively.
